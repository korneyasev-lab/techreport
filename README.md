# Еженедельный контроль технологии

Десктопное приложение для создания еженедельных отчётов контроля технологических процессов производства.

## Возможности

- Создание структурированных еженедельных отчётов
- Заполнение 3 тематических блоков:
  - Входной контроль сырья
  - Технология и оборудование
  - Брак, температура и технологические приёмы
- Экспорт отчётов в форматы PDF и DOCX
- Архив с просмотром и удалением сохранённых отчётов
- Адаптивный интерфейс под Windows/macOS/Linux
- Автоматический выбор текущей недели

## Установка

### Требования
- Python 3.8 или выше
- tkinter (обычно идёт в комплекте с Python)

### Шаги установки

1. Клонируйте репозиторий:
```bash
git clone https://github.com/korneyasev-lab/techreport.git
cd techreport
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Запустите приложение:
```bash
python main.py
```

## Сборка exe для Windows

Для создания исполняемого файла используйте PyInstaller:

```bash
pyinstaller --onefile --windowed --name="TechReport" main.py
```

Готовый exe будет в папке `dist/`

### GitHub Actions

Проект настроен для автоматической сборки exe через GitHub Actions при пуше в ветку `main`.

## Структура проекта

```
techreport/
├── main.py          # Точка входа
├── gui.py           # Графический интерфейс
```

## Использование

### 1. Создание нового отчёта

1. Запустите приложение
2. Нажмите "Создать новый отчёт"
3. Выберите год, месяц и неделю
4. Нажмите "Начать заполнение"

### 2. Заполнение блоков

Отчёт состоит из 3 блоков:

**Блок 1: Входной контроль сырья**
- Отметьте отклонения в поступившем сырье
- Укажите номера партий и комментарии

**Блок 2: Технология и оборудование**
- Отметьте участки без нарушений
- Укажите исправное оборудование
- Добавьте комментарии при необходимости

**Блок 3: Брак, температура и приёмы**
- Опишите случаи брака
- Укажите температуру в цехе и на складе
- Отметьте использованные технологические приёмы

### 3. Сохранение отчёта

1. Заполните все необходимые поля
2. На последнем блоке нажмите "Сохранить отчёт"
3. Выберите формат экспорта (PDF или DOCX)
4. Отчёт сохранится в папке `reports/`

### 4. Просмотр архива

1. На главном экране нажмите "Архив отчётов"
2. Просмотрите список сохранённых отчётов
3. Откройте отчёт двойным кликом или нажмите "Просмотр"
4. Удалите ненужные отчёты кнопкой "Удалить"

## Конфигурация

### Изменение структуры отчёта

Отредактируйте файл `config.py`:
- `TOTAL_BLOCKS` - количество блоков
- `REPORT_BLOCKS` - структура каждого блока

### Настройка интерфейса

Отредактируйте файл `configgui.py`:
- `FONTS_WINDOWS` / `FONTS_MACOS` - размеры шрифтов
- `COLORS` - цветовая схема
- `README_TEXT` - текст инструкции на главном экране

## Типы полей в отчёте

- `checkbox_group` - группа чекбоксов
- `checkbox_group_with_text` - чекбоксы + текстовое поле
- `text_large` - большое текстовое поле (3-4 строки)
- `text_medium` - среднее текстовое поле (2 строки)
- `text_small` - однострочное поле
- `yes_no` - выбор Да/Нет

## Разработка

### Запуск в режиме разработки

```bash
python main.py
```

### Архитектура

- **main.py** - инициализация приложения
- **gui.py** - отвечает только за отрисовку и события UI
- **logic.py** - вся бизнес-логика (сохранение, валидация, экспорт)
- **config.py** - конфигурация структуры отчётов
- **configgui.py** - конфигурация GUI

Принцип: GUI не знает о логике сохранения, логика не знает о tkinter.
