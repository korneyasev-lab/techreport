# Инструкция по сборке TechReport в .exe

## Требования

- Python 3.8 или новее
- Установленные зависимости из `requirements.txt`

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Сборка для Windows

### Способ 1: Использование bat-файла (рекомендуется)

Просто запустите:
```
build.bat
```

### Способ 2: Вручную

```bash
pyinstaller build.spec
```

## Сборка для Linux/macOS

### Способ 1: Использование shell-скрипта (рекомендуется)

```bash
chmod +x build.sh
./build.sh
```

### Способ 2: Вручную

```bash
pyinstaller build.spec
```

## Результат

После успешной сборки:

- **Windows**: исполняемый файл будет находиться в `dist/TechReport.exe`
- **Linux/macOS**: исполняемый файл будет находиться в `dist/TechReport`

## Структура после сборки

```
dist/
├── TechReport.exe       (исполняемый файл для Windows)
├── database/            (база данных СНАРУЖИ .exe!)
│   └── config.db        (если была создана)
├── reports/             (папка для сохраненных отчетов)
└── templates/           (шаблоны документов)
```

## ⚠️ ВАЖНО: База данных СНАРУЖИ .exe

База данных **специально НЕ упакована** внутрь исполняемого файла!

**Почему:**
- Пользователь может редактировать структуру отчетов через встроенный редактор
- Изменения сохраняются без пересборки .exe
- Можно делиться настройками между пользователями (просто скопировать database/config.db)

**Что это значит:**
- При распространении нужно передавать всю папку `dist/`, а не только .exe
- База данных создается автоматически при первом запуске
- Можно заранее настроить структуру и включить config.db в дистрибутив

## Распространение

Для распространения приложения:

1. Упаковать всю папку `dist/` в ZIP-архив (не только .exe!)
2. Передать пользователям архив
3. Пользователи распаковывают и запускают `TechReport.exe`
4. При первом запуске автоматически создается база данных (если её нет)

## Возможные проблемы

### PyInstaller не найден

```bash
pip install pyinstaller
```

### Антивирус блокирует .exe

Некоторые антивирусы могут блокировать .exe созданный PyInstaller. Это ложное срабатывание. Добавьте файл в исключения антивируса.

### Отсутствуют библиотеки

Если при запуске .exe возникает ошибка о недостающих модулях, добавьте их в секцию `hiddenimports` в файле `build.spec`.

## Дополнительная настройка

### Добавление иконки

1. Создайте или найдите .ico файл
2. В файле `build.spec` измените строку:
   ```python
   icon=None  # на icon='path/to/icon.ico'
   ```

### Изменение имени файла

В файле `build.spec` измените параметр:
```python
name='TechReport'  # на желаемое имя
```

### Включение консольного окна (для отладки)

В файле `build.spec` измените:
```python
console=False  # на console=True
```
